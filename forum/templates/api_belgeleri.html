{{ ikon('telefon') }} {{ ayarlar.SITE_ADI }} API (v1)

Forumu mobil uygulamadan ya da kendi programından kullanmak için JSON tabanlı REST API. Kimlik doğrulaması için ya POST /api/v1/giris ile anahtar al, ya da profilinden anahtar oluştur. Anahtarı her istekte Authorization: Bearer <anahtar> başlığıyla gönder. Kişisel veriler (ad, doğum tarihi, adres) API'de hiçbir zaman döndürülmez. Hatalar {"hata": "..."} biçimindedir: 401 kimlik, 422 kural ihlali, 404 bulunamadı.

Örnek

curl -X POST {{ request.host_url }}api/v1/giris -H "Content-Type: application/json" \
     -d '{"takma_ad": "ayse", "sifre": "forum1234", "cihaz": "Telefonum"}'

curl {{ request.host_url }}api/v1/oylamalar -H "Authorization: Bearer agr_..."

curl -X POST {{ request.host_url }}api/v1/oylamalar/12/oy -H "Authorization: Bearer agr_..." \
     -H "Content-Type: application/json" -d '{"secim": "EVET"}'

Uygulama olarak kurmak

Site telefona ve bilgisayara uygulama olarak kurulabilir. Telefonda tarayıcı menüsünden “Ana ekrana ekle”yi, bilgisayarda Chrome ya da Edge adres çubuğundaki “Yükle” simgesini kullan. Uygulama kendi penceresinde açılır ve bağlantı kesilince çevrimdışı sayfası gösterir.
